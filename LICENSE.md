# AGR data: CC BY 4.0

The orthology and gene data are from the Alliance of Genome Resources
Consortium (AGR). AGR data use the Creative Commons Attribution 4.0
International license (CC BY 4.0). The MIT license for package code does
not replace this data license.

- Source: <https://www.alliancegenome.org/downloads>
- License: <https://creativecommons.org/licenses/by/4.0/>

The package contains a modified subset of the AGR data. It selects
species, genes, and gene pairs and changes the table structure. It adds
gene identifiers and species names from the sources below. These changes
do not imply endorsement by AGR.

The source data are supplied without warranties under the license terms.
